# Fictional Student Dataset

## Project description
This project contains a fictional dataset of 20 students. It was created for an academic assignment using Python and CSV.

## Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score

## Files
- `students.csv` — the dataset.
- `main.py` — Python program that reads and displays the dataset.

## How to run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

## Note
All records and student IDs are fictional and created for educational purposes. They do not represent real students.
